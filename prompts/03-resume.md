# Prompt — retomar trabalho

Retome o repositório sem depender do histórico da conversa.

1. Verifique Git e leia harness, `AGENTS.md` e o inventário de skills.
2. Compare o relato com arquivos/diff atuais; fontes versionadas prevalecem.
3. Identifique o slice autorizado incompleto cujos bloqueadores terminaram.
4. Carregue somente regras, Source IDs, handoffs, skill aplicável e código necessário.
5. Apresente estado confirmado, inconsistências, próximo passo mínimo e validação.
6. Prossiga apenas no escopo autorizado. Não repita evidência ainda válida sem razão.
